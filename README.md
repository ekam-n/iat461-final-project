# IAT 461 Final Project

Predicting whether a film will be highly rated by audiences, built for the
final assignment in IAT 461 (Applied Data Science, SFU).

I'm acting as the data scientist for a client proposal from a classmate. The
client, Silver Screen Studios (fictional), wants to know whether a film is
likely to reach an IMDb rating of 8.0 or higher using only information
available before release, to help decide which projects get production
funding. The data is the IMDb Top 1000 dataset from Kaggle.

## Contents
- `notebook.ipynb` — main project notebook (EDA, modeling, interpretation)
- `data/` — dataset and column dictionary
